📊 TECHNICAL DETAILS
─────────────────────────────────────────────────────────────────────────────

Image Processing:
  - File Upload: FileReader API → Base64 → Data URI
  - Camera: Canvas API → JPEG 80% quality → Data URI
  - Storage: Base64 string in hidden input field

Storage Format:
  data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEA...

Database Column:
  Gadgets.image_url (LONGTEXT - can store up to 4GB)

Network:
  - Sent as JSON in request body
  - No separate upload endpoint needed
